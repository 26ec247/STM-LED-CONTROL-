# STM-LED-CONTROL-
An embedded systems project using STM 32 microcontroller to control LED blinking through GPIO programming
STM32 LED Control System
Project Overview
This project demonstrates LED control using an STM32 microcontroller through GPIO programming.
Objective
To understand GPIO output configuration and digital signal control using an STM32 microcontroller.
Components Required
STM32 development board
LED
Resistor
Breadboard
Jumper wires
Working Principle
STM32 initializes the GPIO pin as an output.
The microcontroller sends a HIGH signal to turn ON the LED.
It sends a LOW signal to turn OFF the LED.
This process repeats continuously to create blinking.
Applications
Embedded systems learning
Digital output control
Indicator systems
Microcontroller interfacing
Programming Language
C
Development Environment
STM32CubeIDE
