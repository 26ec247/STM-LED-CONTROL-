# STM32 LED Control - Working

## How It Works

1. STM32 initializes the GPIO pin as an output.
2. The GPIO pin sends a HIGH signal.
3. The LED turns ON.
4. The GPIO pin sends a LOW signal.
5. The LED turns OFF.
6. This process repeats continuously.
